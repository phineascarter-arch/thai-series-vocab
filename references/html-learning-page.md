# HTML 學習手帳

適用於追泰劇詞彙的單一 HTML 交付。視覺參考為已實作的 EP01：奶油紙色、墨綠文字、少量金色標籤、手帳卡片、可切換深色。手機一欄、桌面多欄；不需要把旅行手帳的唱片動畫或旅遊內容帶入。

## 素材與範本

`../assets/learning-page.html` 提供已操作驗證過的 HTML/CSS/JS 起點；其中 `__LESSON_DATA__` 必須替換成 JSON 陣列。它仍帶有 EP01 與 Girl Rules 的示範文字，需要依本次任務更新，不可原樣當成其他集數的成品。範本沒有內嵌該集台詞；內容來自本次已核實的字幕或既有核實筆記。

每筆資料包含：

```json
{
  "id": 1,
  "part": 1,
  "time": "00:45",
  "thai": "已核實的泰文原文節錄",
  "meaning": "繁中自然翻譯",
  "split": "學習用斷詞",
  "gloss": "繁中逐詞解釋",
  "ipa": "逐音節標準讀音",
  "tones": "低・中",
  "hint": "母音長短、送氣與尾音提示",
  "usage": "人物關係與語氣",
  "url": "實際來源回看連結"
}
```

範本用 `data[id - 1]` 存取條目，故 ID 應從 1 連續編號。無時間碼或無影片 URL 時，修改對應 UI 與匯出邏輯，顯示「來源未提供時間碼」／文字出處，不產生假時間碼或空連結。字典來源只列出實際查閱項目。

## 每次套用必做的調整

- 更換頁面標題、主標題、集數、來源影片、分段選單與條目範圍。計算所有卡數，不沿用範本的 47、20／9／9／9。
- 檢查整個檔案中 `EP01`、`Girl Rules`、`girl-rules-ep01-v1`、`47` 等範例值，連同 JS 內的測驗顯示、下載檔名、CSV 牌組、進度備份的 `episode` 都要更新；不要只修改畫面。
- localStorage key 包含劇名 slug、集數與資料版本。匯入進度檢查同一劇集與集數，避免別部劇相同 EP 編號的紀錄混入。若條目會重新排序，使用穩定 ID 或對照遷移，不能讓舊收藏指向另一句。
- 儲存完整頁面於 outputs，勿依賴工作區的 Python、JSON 檔或伺服器。JSON 內嵌時將 `<` 轉成 `\u003c` 或適當跳脫 `</script>`。字幕文字用 `textContent` 等安全方式呈現，不送進 `innerHTML`。
- 從同一份資料產生三種交付與網頁匯出，避免 CSV、HTML、筆記內容不一致。牌組保留劇名，但不同集數檔名需可區分。

## 必要互動與退路

- 搜尋泰文、繁中與 IPA；依 Part 篩選、只看收藏、已學會／未學會。
- 每張卡可開詳細筆記，列出意思、教學斷詞、逐詞解釋、IPA、中文聲調、發音提示、語氣與來源回看。
- 隱藏中文時可按鈕揭示，保留可讀的鍵盤操作；詳細筆記可按 Escape 關閉。
- 收藏與學會狀態存 localStorage，標示僅同一瀏覽器；遇儲存限制仍能學習，提供 JSON 進度備份／合併匯入。
- 合成語音只選 `th`／`th-TH` 聲音，支援一般與慢速；沒有聲音或播放失敗時提示。只偵測到聲音不能宣稱實際播放成功，更不能當成演員發音核對。
- 測驗從目前篩選結果抽最多五題；題目不足就縮減，沒有題目給提示。錯誤選項可來自本集其他條目，但去除重複意思，避免多個同義正解；顯示正誤回饋與結果。
- CSV 匯出正確處理雙引號、欄位換行與 UTF-8，保持兩欄與 Anki 指令頭。下載筆記包含來源類型、時間精度與發音限制。
- 泰文合成語音非演員原聲；網路離線時學習卡片仍可用，但影片與某些裝置語音可能不可用，不宣稱全部功能離線可用。

## 檢查與交付

以可用工具驗證 JS 語法、內嵌資料可解析、卡數與分段計數、重複原句、IPA 音節與聲調標籤對應，以及匯出 CSV 可讀回。操作檢查至少包含搜尋、篩選、詳細筆記、收藏與重新載入、中文揭示、測驗至結果；修改後只重驗受影響部分。

有瀏覽器時檢查窄螢幕文字與導覽沒有溢出；預覽伺服器僅測試用，交付檔本身不需伺服器，結束時停掉自己啟動的程序。交付連結指向實際 HTML；可附預覽圖。不要把本機預覽 URL 當永久部署網址，也不要未經要求發布到 Sites、Vercel 或更新使用者的網站。
