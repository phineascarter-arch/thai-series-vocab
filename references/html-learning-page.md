# HTML 學習手帳

適用於追泰劇詞彙的單一 HTML 交付。視覺參考為已實作的 EP01：奶油紙色、墨綠文字、少量金色標籤、手帳卡片、可切換深色。手機一欄、桌面多欄；不需要把旅行手帳的唱片動畫或旅遊內容帶入。

## 素材與範本

`../assets/learning-page.html` 提供已操作驗證過的 HTML/CSS/JS 起點；其中 `__LESSON_DATA__` 必須替換成句子 JSON 陣列，`__WORD_DATA__` 必須替換成逐詞音訊 JSON 陣列（沒有音訊時填空陣列並明示限制）。它仍帶有 EP01 與 Girl Rules 的示範文字，需要依本次任務更新，不可原樣當成其他集數的成品。範本沒有內嵌該集台詞；內容來自本次已核實的字幕或既有核實筆記。

每筆資料包含：

```json
{
  "id": 1,
  "part": 1,
  "time": "00:45",
  "thai": "已核實的泰文原文節錄",
  "meaning": "繁中自然翻譯",
  "split": "學習用斷詞",
  "gloss": "繁中逐詞解釋",
  "romanization": "khaaw thoot thii na",
  "tones": "低・中",
  "hint": "母音長短、送氣與尾音提示",
  "usage": "人物關係與語氣",
  "url": "實際來源回看連結"
}
```

範本用 `data[id - 1]` 存取條目，故 ID 應從 1 連續編號。無時間碼或無影片 URL 時，修改對應 UI 與匯出邏輯，顯示「來源未提供時間碼」／文字出處，不產生假時間碼或空連結。字典來源只列出實際查閱項目。

## 每次套用必做的調整

- 更換頁面標題、主標題、集數、來源影片、分段選單與條目範圍。計算所有卡數，不沿用範本的 47、20／9／9／9。
- 檢查整個檔案中 `EP01`、`Girl Rules`、`girl-rules-ep01-v1`、`47` 等範例值，連同 JS 內的測驗顯示、下載檔名、CSV 牌組、進度備份的 `episode` 都要更新；不要只修改畫面。
- localStorage key 包含劇名 slug、集數與資料版本。匯入進度檢查同一劇集與集數，避免別部劇相同 EP 編號的紀錄混入。若條目會重新排序，使用穩定 ID 或對照遷移，不能讓舊收藏指向另一句。
- 儲存完整頁面於 outputs，勿依賴工作區的 Python、JSON 檔或伺服器。JSON 內嵌時將 `<` 轉成 `\u003c` 或適當跳脫 `</script>`。字幕文字用 `textContent` 等安全方式呈現，不送進 `innerHTML`。
- 從同一份資料產生三種交付與網頁匯出，避免 CSV、HTML、筆記內容不一致。牌組保留劇名，但不同集數檔名需可區分。

## 必要互動與退路

- 搜尋泰文、繁中與 羅馬拼音；依 Part 篩選、只看收藏、已學會／未學會。
- 每張卡可開詳細筆記，列出意思、教學斷詞、逐詞解釋、羅馬拼音、中文聲調、發音提示、語氣與來源回看。
- 隱藏中文時可按鈕揭示，保留可讀的鍵盤操作；詳細筆記可按 Escape 關閉。
- 收藏與學會狀態存 localStorage，標示僅同一瀏覽器；遇儲存限制仍能學習，提供 JSON 進度備份／合併匯入。
- 合成語音只選 `th`／`th-TH` 聲音，支援一般與慢速；沒有聲音或播放失敗時提示。只偵測到聲音不能宣稱實際播放成功，更不能當成演員發音核對。
- 測驗從目前篩選結果抽最多五題；題目不足就縮減，沒有題目給提示。錯誤選項可來自本集其他條目，但去除重複意思，避免多個同義正解；顯示正誤回饋與結果。
- CSV 匯出正確處理雙引號、欄位換行與 UTF-8，保持兩欄與 Anki 指令頭。下載筆記包含來源類型、時間精度與發音限制。
- 泰文合成語音非演員原聲；網路離線時學習卡片仍可用，但影片與某些裝置語音可能不可用，不宣稱全部功能離線可用。

## 檢查與交付

以可用工具驗證 JS 語法、內嵌資料可解析、卡數與分段計數、重複原句、羅馬拼音 音節與聲調標籤對應，以及匯出 CSV 可讀回。操作檢查至少包含搜尋、篩選、詳細筆記、收藏與重新載入、中文揭示、測驗至結果；修改後只重驗受影響部分。

有瀏覽器時檢查窄螢幕文字與導覽沒有溢出；預覽伺服器僅測試用，交付檔本身不需伺服器，結束時停掉自己啟動的程序。交付連結指向實際 HTML；可附預覽圖。不要把本機預覽 URL 當永久部署網址，也不要未經要求發布到 Sites、Vercel 或更新使用者的網站。

羅馬拼音使用 SKILL.md 的同一套教學拼寫，資料欄位為 `romanization`；不沿用舊音標值。頁面、搜尋、詳細筆記及 CSV／Markdown 匯出都必須讀取同一欄位，聲調另顯示中文標籤。修改拼音時保留卡片 ID 與既有進度儲存 key。

已產生的 MP3 用 `audio` 欄位放入 `data:audio/mpeg;base64,...`，單檔頁面以 HTML audio 播放；正常播放 rate 為 1，慢速約 0.71，保留音高。保留原生播放器作手動播放退路，顯示實際錯誤。不能把「列出聲音」視為播放成功。

iPhone 使用情境：播放必須由點按直接觸發，不自動播放；使用標準 HTML audio 與可解碼音訊，提供原生播放控制及正常／慢速。詳細筆記開啟時載入該句音訊，不能讓手動播放器呈現無來源的停用狀態。未使用實體 iPhone 測試時明示限制，不能以桌面通過冒充 iOS 實測。

## 預設語音

- 使用者已選定 **Microsoft Premwadee Neural 泰語女聲**，voice ID 固定為 `th-TH-PremwadeeNeural`，語系 `th-TH`。後續劇集預設沿用；未經使用者要求，不自行換聲音。
- 使用可用的相同 voice ID 合成來源。既有產製方式是第三方 Python 套件 `edge-tts` 呼叫 Microsoft Edge 線上語音服務；`edge-tts` 是工具，不是聲音供應商，也不是 Microsoft 官方 SDK。不要把這個流程宣稱為已開通或付費使用 Azure API。
- 工具已可用時，`edge_tts.Communicate(泰文原句, voice="th-TH-PremwadeeNeural", rate="+0%", pitch="+0Hz", volume="+0%").save(MP3路徑)` 產生正常速度音檔。慢速透過播放器 playbackRate 調整，不重複合成。依目前權限取得必要工具，不能沿用其他工作區的絕對路徑。
- 只將本次選定的泰文學習短句送去合成。每張卡確認 MP3 非空且可解碼，再內嵌；合成失敗可重試，單句最多三次。仍失敗時保留筆記與影片回看並說明缺少音訊，不用假音檔、不暗中換回 Windows Pattara 或其他聲音。未完成音訊時明示限制，不阻擋其他格式交付。
- 在頁面標示「Microsoft Premwadee Neural 女聲／合成語音，非演員原聲」。已內嵌音檔的頁面播放時不需呼叫線上語音服務或安裝泰文語音。沒有音訊時，若要改用不同聲音，先讓使用者選擇。
- 原版 EP01 曾用 Windows 內建 Microsoft Pattara 經本機 Windows 語音引擎合成 WAV，現已被使用者選定的 Premwadee Neural MP3 取代。此資訊只用於辨識與避免回退，不能把舊聲音視為預設。

## 逐詞音訊與聽音選詞

- 依每句 `split` 的教學詞塊與 `gloss` 逐項配對，不以泰文字母或任意空格切割。配對數量不同先核對，不能將錯誤中文掛到詞上。多音節詞塊完整播放，不冒稱每個字母單獨發音。
- 獨立內嵌 `wordData` JSON，格式為 `{id, thai, meanings, cards, audio}`：id 使用穩定唯一值，thai 為詞塊原文，meanings 為該詞在各句的解釋陣列，cards 為所屬句子 ID 陣列，audio 為 Premwadee MP3 data URI。同一詞跨句去重，保留語境差異；按鈕上的中文用當句 gloss，不拿其他句義項替代。
- 將每個詞塊顯示為可點按的播放按鈕，旁列當句中文，提供可讀標籤及載入／播放錯誤提示。只列音訊成功的詞為可播放；失敗詞不能假裝播放。優先使用已選的 `th-TH-PremwadeeNeural`。
- 聽音選詞的題目來自目前 Part、搜尋、收藏及學會篩選所涵蓋的詞塊，去重後每輪最多五題；選項以一個正解加最多三個本集不同詞塊組成，選項不足時縮減。播放後選泰文，作答前不顯示正解或中文；作答後顯示答案、語境解釋、重播與原句入口。
- 題目只計第一次作答，不重複加分。選項作答後停用；無題目清楚提示。原句的既有五題中文測驗保留，與新聽音遊戲分開。
- 播放句子、單字或遊戲時先停止其他播放器，避免重疊。iPhone 由使用者點按直接播放內嵌 MP3；原生控制項可重聽。此功能不錄音，也不是口音／發音評分；使用者另要求麥克風功能時需另外規劃。
- 驗證所有詞塊／中文對齊、去重數、所屬句子 ID 與 MP3；實測同句多個詞按鈕、播放進度、遊戲篩選、重播、錯題回饋、每輪結果與原句跳轉。修改字卡功能時保留既有收藏與學會 ID 及 localStorage key。
