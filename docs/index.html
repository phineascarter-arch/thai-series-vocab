A GENTLE PRONUNCIATION GUIDE

先聽聲調，再慢慢開口。

中平穩
低低位
降高往低
高高位上揚
升低再升

羅馬拼音按音節用空格分開，聲調另看中文標籤。aa、ii、uu、ee、oo 表示長母音；ae／aae 為短／長的開口 e，aw／aaw 為短／長的開口 o，oe／ooe 為短／長的不圓唇央母音，ue／uue 為短／長的不圓唇高母音。ai、ao、uai 是同一音節。ph、th、kh 是送氣的 p、t、k，不讀英語 f 或 th；j、ch 近似不送氣／送氣的「ㄐ／ㄑ」，ng 是鼻音。尾音 p、t、k 收住不爆破。這是本筆記統一的教學拼音，不照英文拼字規則讀；請搭配泰文語音。

發音按鈕使用裝置的泰文合成語音，非演員原聲；可在詳細筆記中用慢速練習。
